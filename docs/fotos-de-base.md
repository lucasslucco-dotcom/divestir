# Fotos de base do catálogo

As fotos de base são geradas no Higgsfield (modelo GPT Image 2.6, alta qualidade, 2K, 4:5), no estilo manequim invisível e no fundo cinza `#E9E9E7`. Elas ficam em `public/catalogo/` com o nome `peca-cor-lado.jpg`, e o banco aponta para elas na tabela `peca_imagens`.

Método: a versão preta de frente de cada peça é a matriz. As costas e as cores branca e creme são geradas a partir dela, para a silhueta não mudar quando o cliente troca de cor.

Os códigos abaixo são dos trabalhos no Higgsfield. As gerações feitas pelo chat não aparecem no histórico do site do Higgsfield, então é por esse código que se acha cada foto de novo.
